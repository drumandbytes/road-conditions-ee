# Contributing

Teesilm is a solo-maintained project. I'm not accepting external pull
requests right now — an unsolicited PR will most likely sit unreviewed, so
please don't spend time putting one together.

Bug reports and feature requests are very welcome via
[Issues](https://github.com/drumandbytes/road-conditions-ee/issues) — pick
the template that fits, or open a blank issue if neither does.

Found a security vulnerability? See [SECURITY.md](SECURITY.md) instead of
filing a public issue.
